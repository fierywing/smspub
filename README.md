# smspub 短信转发中心

把 USB 蜂窝模组接到 Linux 主机，就能在网页上管理多张 SIM 卡，收发短信，并将新消息推送到手机、聊天工具或邮箱。

## 能做什么

- **多卡收发短信**：自动发现模组、掉线重连，支持中文和长短信。
- **消息通知**：支持 Bark、Telegram、钉钉、飞书、邮件等 11 类通道。
- **网页管理**：查看信号、搜索短信历史、发送短信和管理卡片。
- **网页电话**：支持拨号和接听；部分 ML307A 固件支持实验性浏览器收听与麦克风通话。

一个程序即可运行，网页已内置，短信历史保存在本地。

## 测试过的设备型号
ML307系列（AC版本都行,A版本全网通C版本只支持移动和联通）

## 快速开始

准备一台 Linux 主机、支持 AT 短信指令的 USB 蜂窝模组和可用 SIM 卡。运行用户需要有串口读写权限。

**使用 Docker**：按[部署指南](docs/DEPLOYMENT.md)准备配置并启动，文档提供可直接复制的 Compose 模板。

**从源码运行**：安装 Go 1.27.1 或更高兼容版本，在项目目录执行：

```bash
go build -o smspub ./cmd/smspub
./smspub -listen 127.0.0.1:8080
```

打开 [http://localhost:8080](http://localhost:8080)，接入模组并等待卡片出现。在卡片设置中填写备注和号码，在全局设置中添加通知通道，即可开始使用。

服务没有内置登录，请仅通过可信入口访问。部署在远程主机时，使用部署指南中的 SSH 转发或带认证的 HTTPS 入口。

## 使用前了解

- 配置默认保存在 `config.json`，短信历史位于启动目录的 `data/`；迁移和备份时一起保留。
- 短信和电话能力取决于模组、固件、SIM 卡及运营商服务。
- 浏览器麦克风需要可信 HTTPS 或 localhost，并允许麦克风权限。
